Upload comments you wrote somewhere else

Pick the way that is easiest for you. You can also use Write a comment.

From a Word file (.docx)

Use a review written in Word. Lists with numbers or bullets work. Real Word comments and tables with a Comment column work too. A line that starts with Sec. 35: uses that section as the place, and Fix: becomes the better wording.

Your file is read on your own computer. It is not sent anywhere. You see what was found and choose what to add. Adding the same file twice does not make copies.

From a PDF with notes

Choose the manual and your PDF with sticky notes. Each note becomes a comment with its page number.

Your PDF is read on your own computer. Highlights or drawings with no written note cannot be used; add those with Write a comment. Adding the same file twice does not make copies.

From a spreadsheet (CSV)

Download the sheet, write one comment on each row, then upload it. Keep the column names. Type the manual name exactly as it is in Read manuals.
